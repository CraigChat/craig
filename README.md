# Contributing
Feel free to contribute, you can start a codespace which installs all the nessesary things.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/CraigChat/craig?quickstart=1)

You can also clone the repository and install the nessesary packages with pnpm:
```sh
git clone https://github.com/CraigChat/craig
cd craig
pnpm i
pnpm build
pnpm build-cook # builds the dependencies for kitchen
pnpm db:deploy # updates the database
```
